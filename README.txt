## 💻 Installation & Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/satyajit450/Protfolio.git
```

### 2. Navigate to the Project Folder

```bash
cd SatyajitPortfolio
```

### 3. Open in Visual Studio Code

```bash
code .
```

### 4. Run the Website

- Open `index.html` in VS Code.
- Install the **Live Server** extension if you haven't already.
- Right-click `index.html`.
- Select **Open with Live Server**.

The portfolio will open in your default browser.

You can also open `index.html` directly in a browser.

## 🌐 Deployment

This is a static website and can be hosted using GitHub Pages.

### GitHub Pages Deployment

1. Push the project files to a GitHub repository.
2. Open the repository on GitHub.
3. Navigate to **Settings**.
4. Select **Pages** from the sidebar.
5. Under Build and deployment, select **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder.
7. Click **Save**.
8. Wait for GitHub Pages to publish the website.

Your portfolio will then be accessible through the published GitHub Pages URL.

## ⚙️ Customization

Before publishing, update the following details in `index.html`:

- Your email address
- GitHub profile URL
- LinkedIn profile URL
- Project repository links
- Any personal information you want to display

### Changing the Profile Image

Replace:

```text
assets/profile.png
```

with your preferred photograph.

Keep the filename unchanged, or update the image path in `index.html`.

### Changing the Theme

The primary theme colours can be modified in `style.css`.

```css
:root {
    --bg: #080809;
    --panel: #111113;
    --red: #ff1748;
    --coral: #ff6259;
    --white: #f5f5f4;
    --muted: #a4a1a3;
}
```

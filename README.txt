SATYAJIT SAHU — PORTFOLIO

RUN:
1. Extract this folder.
2. Open the folder in VS Code.
3. Open index.html with the Live Server extension.

PHOTO:
- Your supplied red-lit studio portrait is saved as assets/profile.jpg.
- The hero image is a clean rectangular photo with no decorative circles, dots, or red pattern behind it.
- To use another photo, replace assets/profile.jpg with your own image using the same filename.

BEFORE PUBLISHING:
- Replace YOUR_EMAIL@example.com in index.html.
- Replace YOUR_GITHUB and YOUR_LINKEDIN in the social links.
- Review project descriptions and links so they accurately reflect your work.

Files: index.html, style.css, script.js, assets/profile.jpg
